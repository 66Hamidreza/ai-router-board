# راه‌اندازی عامل‌ها

[بازگشت](../../README.fa.md)

تابلو خودِ ابزارهای عامل را نصب یا به حساب شما وارد نمی‌کند. ابزار را طبق راهنمای رسمی همان محصول نصب کنید، بیرون تابلو یک بار اجرا و احراز هویت کنید و مطمئن شوید در محیط فرایند سرور در دسترس است. سپس سرور را راه‌اندازی کنید یا فهرست عامل‌ها را تازه کنید. نصب بودن فایل اجرایی به‌تنهایی تضمین آماده بودن حساب و مجوز نیست.

| عامل | آماده‌سازی |
|---|---|
| Claude Code | CLI و حساب معتبر؛ با فرمان `claude` در ترمینال همان کاربر قابل اجرا باشد |
| OpenAI Codex | CLI و احراز هویت معتبر؛ فرمان `codex` در دسترس باشد |
| GitHub Copilot | CLI و حساب دارای دسترسی لازم؛ بررسی تشخیص نسخه در Windows ممکن است به راه‌انداز واقعی نیاز داشته باشد |
| OpenCode | CLI و ارائه‌دهندهٔ مدل آن را تنظیم کنید |
| Hermes | CLI و تنظیم ACP فعال؛ `hermes acp --check` باید موفق باشد؛ فرمان سفارشی با `HERMES_COMMAND` قابل تعیین است |
| OpenClaw | CLI، Gateway و دسترسی نشست را طبق تنظیم ارائه‌دهنده آماده کنید |
| Grok | CLI با فرمان پیش‌فرض `grok` و حالت `agent --model grok-4.5 stdio` در SDK اجرا می‌شود؛ حساب و دسترسی مدل را در خود CLI آماده کنید |

سرور از SDK مشترک برای ساخت نشست، دریافت رویداد و توقف عامل استفاده می‌کند. نام‌های قدیمی workspace همچنان `@ai-agent-board/*` هستند. گزینه‌های مدل در فایل‌های نمونه قرار دارند، اما تفسیر آن‌ها به SDK و CLI تعلق دارد؛ [پیکربندی](configuration.md) تفاوت را توضیح می‌دهد.

## اجرای اولین کار

یک پروژه و کارت بسازید. برای تغییر کد مسیر مخزن، شاخه و در صورت نیاز worktree را مشخص کنید. با بردن کارت به حالت اجرا، پنل عامل باز می‌شود؛ عامل و تنظیمات را بازبینی و اجرا را شروع کنید. خروجی زنده، نتیجه و خطاها در همان کارت قابل مشاهده‌اند. پیش از ادغام یا ساخت درخواست تغییر، فایل‌ها و نتیجهٔ آزمون را بررسی کنید.

اگر کار فقط متن عمومی است، مسیر مخزن ندهید و حساسیت را صریحاً عمومی تعیین کنید. کلید فایل امن یکی از مدل‌های رایگان کافی است؛ این مسیر نشست عامل برنامه‌نویسی مبتنی بر CLI ایجاد نمی‌کند.

## گروه‌ها، توقف و زمان اجرا

گروه کاری چند کارت را با سقف هم‌زمانی اجرا می‌کند. worktree اختیاری برای جدا کردن تغییرهاست و جای کنترل دسترسی را نمی‌گیرد. پاک‌سازی خودکار فقط worktree ثبت‌شده و پاک را حذف می‌کند؛ مسیر دارای تغییر یا فعال نگه داشته می‌شود و شاخه باقی می‌ماند.

مهلت پیش‌فرض یک ساعت است و هر کارت می‌تواند 1 تا 240 دقیقه تعیین کند. افزایش زمان الزاماً به معنی افزایش پنجرهٔ متن مدل نیست. در محیط آزمون، `AGENTBOARD_DISABLE_AGENT_STARTUP=1` راه‌اندازی عامل‌ها را غیرفعال می‌کند؛ برای اجرای واقعی آن را بردارید.

## اتصال Hermes به تابلو

افزونه در `integrations/hermes-agent-board` قرار دارد. `AGENT_BOARD_URL` را با درگاه واقعی API، مثلاً `http://localhost:8080`، تنظیم کنید. توکن محدود را ترجیحاً با `AGENT_BOARD_TOKEN_FILE` از فایل 0600 بخوانید؛ `AGENT_BOARD_TOKEN` جایگزین مستقیم آن است. این اعتبارنامه با کلید مدل رایگان تفاوت دارد. جزئیات نصب پروفایل و ابزارها در [راهنمای افزونه](../../integrations/hermes-agent-board/README.md) آمده است.

## نمونه و گام بعد

برای آزمودن مسیر متن عمومی، عنوان `Summarize article` و توضیح کوتاه عمومی وارد کنید، حساسیت را `public` بگذارید و مسیر مخزن را خالی نگه دارید. عامل صریح یا عامل پیش‌فرض پروژه می‌تواند بر انتخاب خودکار مقدم شود؛ نتیجه را در «Routing & usage» بررسی کنید.

گام بعد: [پیکربندی](configuration.md) · [مسیریابی](routing.md) · [رفع خطاهای رایج](faq.md).

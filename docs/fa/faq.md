# پرسش‌های رایج

[بازگشت](../../README.fa.md)

این پاسخ‌ها برای تشخیص خطاهای رایج نصب، مسیریابی و اجرای عامل‌ها هستند. پیش از ارسال گزارش عمومی، کلیدها و اطلاعات خصوصی را حذف کنید.

## چرا مدل رایگان انتخاب نمی‌شود؟

باید حساسیت صریحاً `public` باشد و مسیر مخزن نداشته باشید. در مسیریابی خودکار واژه‌های ترجمه، خلاصه، دسته‌بندی یا پیش‌نویس لازم‌اند؛ واژه‌های امنیت و بک‌اند اولویت بالاتری دارند. عامل صریح نیز بر مسیریابی خودکار مقدم است. [قواعد](routing.md) را ببینید.

## چرا فایل کلید هست ولی ارائه‌دهنده آماده نیست؟

نام و پوشه را بررسی کنید: `groq.key`، `gemini.key` یا `openrouter.key`. فایل باید معمولی، غیرخالی و بدون دسترسی گروه و دیگران باشد. پس از ساخت یا تغییر آن سرور را بازراه‌اندازی کنید؛ نتیجهٔ نبود کلید هم در حافظه نگه داشته می‌شود. متغیر مستقیم کلید API در مسیر رایگان پشتیبانی نشده است.

## چرا کارت پس از محدودیت سهمیه بیکار می‌شود؟

مجموعهٔ ارائه‌دهندگان زمان تلاش بعدی را گزارش می‌کند و مدیر اجرا کارت را بیکار می‌کند. زمان‌بندی خودکار شروع مجدد وجود ندارد؛ پس از زمان ثبت‌شده دوباره اجرا کنید. خطای قطعی هر ارائه‌دهنده نیز آن را ده دقیقه کنار می‌گذارد.

## آیا سطح صفر یا ارتقای چندمرحله‌ای فعال است؟

سطح صفر رزرو شده و رد می‌شود. پاسخ نامقبول سطح 1 یک بار به Codex ارتقا می‌یابد. تابع کمکی سطح 2 به Claude وجود دارد، ولی کنترل و ارتقای خودکار پاسخ عامل‌های برنامه‌نویسی فعال نیست.

## چرا عامل در دسترس نیست؟

CLI، ورود حساب و محیط `PATH` فرایند سرور را بررسی کنید. نصب در ترمینال دیگری لزوماً برای سرویس در دسترس نیست. گزینهٔ `AGENTBOARD_DISABLE_AGENT_STARTUP` را نیز بررسی کنید. برای Hermes از `hermes acp --check` استفاده کنید.

## چرا تغییر فایل تنظیم ریشه اثر ندارد؟

سرور و Vite از پوشه‌های کاری جدا تنظیم می‌خوانند. فایل‌ها را در `packages/server/.env` و `packages/client/.env` قرار دهید یا متغیر را در محیط صادر کنید. تغییر کلید مرورگر به بازراه‌اندازی/ساخت رابط نیاز دارد.

## Docker همهٔ برنامه را اجرا می‌کند؟

بله، با `docker compose --profile app up --build -d app` رابط و API روی درگاه محلی 8080 اجرا می‌شوند. اجرای سادهٔ `docker compose up -d db` فقط PostgreSQL را بالا می‌آورد. پروفایل برنامه به‌طور پیش‌فرض از SQLite استفاده می‌کند؛ تغییر اتصال داده‌ها را مهاجرت نمی‌دهد. ابزارهای عامل و اعتبارنامه‌ها جدا آماده می‌شوند. [راهنمای نصب](install.md) را ببینید.

## آیا «رایگان» و هزینهٔ صفر یعنی هیچ صورتحسابی ندارم؟

خیر. محدودیت مدل و BYOK به تنظیم حساب ارائه‌دهنده وابسته است. هزینهٔ صفر در ثبت تلاش رایگان، حسابرسی صورتحساب واقعی نیست. مقدار مصرف `unknown` نیز به معنی دادهٔ نامعلوم است، نه صفر.

## آیا کار محرمانه کاملاً روی دستگاه می‌ماند؟

خیر. این برچسب مسیر رایگان را می‌بندد؛ عامل انتخاب‌شده ممکن است از سرویس ابری خود استفاده کند. سیاست داده و دسترسی عامل را جدا بررسی کنید.

## چرا ساخت یا آزمون شکست می‌خورد؟

ابتدا وابستگی‌ها را نصب و `npm run build:shared` را اجرا کنید. خطای دریافت بسته معمولاً نیازمند دسترسی registry است. آزمون سرور با `npm test -w @ai-agent-board/server` و دروازهٔ کامل با `npm run gate:required` اجرا می‌شود. آزمون مرورگر به مرورگر Playwright و وابستگی‌های سیستم آن نیاز دارد.

## گام بعد

اگر مشکل باقی ماند، نسخهٔ برنامه، فرمان اجرا و خروجی پاک‌سازی‌شده را طبق [راهنمای مشارکت](contributing.md) گزارش کنید. برای کلید و متغیرها [پیکربندی](configuration.md) و برای محدودیت ارسال داده [امنیت](security.md) را ببینید.
